# 🎯 AI Career Decision Coach

An AI-powered application built using Amazon PartyRock that helps students make informed career decisions based on their skills, goals, and time availability.

## 🚀 Live App
👉 https://partyrock.aws/u/mahakshrivastava13/uHRCcWtoz/new-app-uHRCcWtoz

## 💡 Features
- 🎯 Personalized Career Path Recommendation  
- 📊 Career Feasibility Score (0–100)  
- 🧠 Skill Gap Analysis  
- 🗺️ Step-by-step Roadmap (3–6 months)  
- 📅 Weekly Progress Tracker  
- ⚠️ Reality Check (challenges & risks)  
- 🔁 Backup Plan  
- 💬 Harsh Truth Mode  
- 🎯 Daily Action Plan  

## 🧩 Inputs
- Qualification  
- Skills  
- Career Goal  
- Time Availability 

- Interest Level  

## 📊 Outputs
- Career Suggestions  
- Roadmap  
- Score & Analysis  
- Planning & Strategy  

## 🎯 Purpose
This project aims to solve career confusion among students by providing structured, realistic, and actionable guidance using AI.

## 🛠️ Tech Used
- Amazon PartyRock (Generative AI)
